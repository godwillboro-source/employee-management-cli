# Employee Management CLI

A lightweight, command-line interface app built in Python for managing employee records efficiently. One can log in as an employer, manager or a normal staff member. The employer can change employee records, the manager can comment on conduct of an employee while the employee can log hours in the system.

---

# Features

* **Add Employees:** Register new employees with details such as name, ID, role, and department.
* **View Records:** Display a structured list or search for specific employee details directly from your terminal.
* **Update Information:** Modify existing employee data easily.
* **Delete Records:** Remove employee entries from the system.
* **Persistent Storage:** Safely saves data using file I/O or a lightweight database.

---

# Requirements

Make sure you have the following installed on your system:
* Python 3.8 or higher
* `pip` (Python package manager)

---

# Installation & Setup

1. **Clone the repository:**
   https://github.com/godwillboro-source/employee-management-cli.git
2. **Create a virtual python environment**
   pipenv shell
3. **Install dependencies**
   pip install pytest
4. **Run the code on your ternminal**
   python3 main.py
